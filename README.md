# Nachbarhand

Prototyp einer App für bezahlte Nachbarschaftshilfe in Garbsen: Gesuche auf einer Karte, Aufwandsentschädigung mit Servicegebühr, Ablauf von der Zusage bis zur Auszahlung.

- Live: https://z6dfczy4jt-code.github.io/nachbarhand/
- Alle Daten sind erfundene Beispiele, es fließt kein echtes Geld.
- Karte: [Leaflet](https://leafletjs.com), Kartenkacheln © [OpenStreetMap](https://www.openstreetmap.org/copyright)-Mitwirkende © [CARTO](https://carto.com/attributions)
